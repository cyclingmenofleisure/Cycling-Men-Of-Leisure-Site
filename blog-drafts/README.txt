HOW THE BLOG DRAFTS FOLDER WORKS
================================
Every Monday, the automatic update adds a blog post to blog.html for each new
episode, built from the episode's show notes in the podcast feed.

Want the full Cohost AI blog post instead? In Buzzsprout, open the episode's
Cohost AI Summary, copy the drafted blog post, and save it in this folder as a
plain text file named with the episode number, for example:

    S5E32.txt

On the next Monday run, that text replaces the auto-generated post for that
episode (even if the post is already on the page), and the file is moved into
the "used" subfolder so it isn't processed twice.
